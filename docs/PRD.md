# GymGym 产品需求文档（PRD）

> 版本 v0.1 · 2026-11 · 面向个人自用的健身记录 App

## 1. 产品定位

**一句话**：一个「好看、顺手、离线可用」的个人健身记录工具：先制定计划，练的时候快速记录每一组，练完回顾进步。

| 维度 | 说明 |
| --- | --- |
| 目标用户 | 我自己：每周去健身房 3–5 次，做力量训练和一些有氧，偶尔居家徒手 |
| 使用场景 | ① 训练前：看今天练什么；② 训练中：单手操作、组间快速记录、计时休息；③ 训练后：看总结、看历史和趋势 |
| 核心价值 | 少思考、少点击：计划自动带出上次重量；一次点击完成一组；自动计时和个人记录（PR）提醒 |
| 形态 | 移动端优先的 PWA（可「添加到主屏幕」像原生 App 一样使用），数据存本机，无需注册登录 |

### 非目标（v1 不做）
- 社交、排行榜、账号体系与云同步（用 JSON 导出/导入代替）
- AI 教练、饮食热量记录
- 视频教学（使用开源动作库的两帧示范图代替）

## 3. 功能清单与范围

### 3.1 动作库
- 数据源：开源 [free-exercise-db](https://github.com/yuhonas/free-exercise-db)（Unlicense 公共领域），876 个动作，含主要/次要肌群、器材、难度、类别、两帧示范图、英文要领。
- 本地化：为全部 876 个动作人工翻译中文名（`scripts/zh-names.txt`），肌群、器材、类别均中文化；搜索同时支持中文和英文。
- 常用标记：约 100 个常用动作置顶并带 ⭐。
- 筛选：8 个部位（胸、背、肩、手臂、腿、臀、核心、有氧）× 12 种器材 × 关键词；或在人体肌肉图上直接点选肌肉。
- 记录方式自动推断：`重量×次数`（杠铃/哑铃/器械…）、`自重次数`（可加负重）、`计时`（平板支撑、拉伸）、`时长+距离`（有氧）。
- 自定义动作：名称、主要肌肉（点人体图）、器材、记录方式、备注。

### 3.2 训练计划
- 字段：名称、颜色标签、训练日（周一~周日多选）、动作列表；每个动作：组数、每组次数（或时长）、目标重量（可空，空则沿用上次重量）、组间休息。
- 操作：新建 / 编辑 / 复制 / 删除；动作上移下移、移除；按计划开始训练。
- 推荐模板 5 套，一键生成 1–3 个计划。
- 首页按星期自动展示「今日计划」。

### 3.3 训练记录（进行中）
- 计时：训练总时长实时显示；屏幕常亮（Wake Lock）。
- 逐组记录：上次数据 / 重量 / 次数 / ✓；点「上次」一键套用；未填写时点 ✓ 自动用上次数据补全。
- 组类型：正式 / 热身（W）/ 递减（D）/ 力竭（F）；热身组不计入容量和 PR。
- 组间休息：完成一组自动开始倒计时，±15 秒、跳过；结束时振动 + 提示音 + Toast。
- 动作管理：添加（多选）、替换、上下移动、删除、调整该动作休息时间。
- 训练备注、重命名；放弃训练。
- 状态持久化到 localStorage，刷新/切后台不丢。

### 3.4 训练总结
- 时长、训练容量（Σ重量×次数）、完成组数、动作数、第 N 次训练。
- 个人记录检测：最大重量 / 预估 1RM（Epley）/ 最多次数 / 最长时长。
- 本次练到的肌肉热力图；主观感受 5 档 + 心得；保存为计划。

### 3.5 记录与统计
- 历史：月历（按计划颜色标记训练日，可点选某天筛选）+ 训练列表 → 训练详情（每组明细、再练一次、保存为计划、删除）。
- 统计：近 4 周 / 12 周 / 1 年；KPI（次数、时长、容量、连续训练周数）；趋势柱状图（容量/次数/时长）；部位分布（人体热力图 + 条形图）；个人记录 Top 8；体重曲线。
- 单动作：最大重量、预估 1RM、训练次数、进步曲线、最近 5 次记录。

### 3.6 设置
- 昵称、重量单位（kg/lb，仅显示）、默认休息时间、振动/提示音、每周起始日、深色/浅色/跟随系统、导出/导入/清空数据、开源致谢。

## 4. 信息架构

```
底部导航
├── 首页        问候 · 本周打卡条 · 本周数据 · 今日计划 · 本周练到的部位 · 最近训练
├── 计划        我的计划列表 · 推荐模板 ──► 计划编辑（选部位→选器材→选动作）
├── ▶ 开始训练  （中间凸起按钮）选择计划/自由训练 ──► 训练进行中 ──► 训练总结
├── 动作库      搜索 · 按部位/点选肌肉 · 器材筛选 · 列表 ──► 动作详情 / 自定义动作
└── 记录        历史（月历 + 列表 ──► 训练详情） · 统计
首页右上角 ⚙ ──► 设置
```

## 5. 数据模型（IndexedDB / Dexie）

| 表 | 主要字段 |
| --- | --- |
| `plans` | id, name, color, days[], exercises[{uid, exerciseId, sets, reps, weight?, duration?, restSec}], createdAt, updatedAt, lastUsedAt |
| `workouts` | id, name, planId?, color, startedAt, endedAt, note, feeling, exercises[{uid, exerciseId, restSec, sets[{id, type, weight?, reps?, duration?, distance?, done}]}] |
| `bodyweights` | id, date(YYYY-MM-DD, 唯一), weight |
| `customExercises` | 与内置动作同结构，`custom: true` |
| localStorage | 设置 `gymgym-settings`；进行中训练 `gymgym-active-workout` |

关键计算：
- 训练容量 = Σ(正式/递减/力竭组 重量 × 次数)
- 预估 1RM（Epley）= w × (1 + r/30)，r ≤ 12
- 肌群负荷 = 主要肌群 1 组计 1，次要肌群计 0.5

## 6. 非功能需求
- **性能**：动作库 JSON（~0.9MB，gzip ~250KB）首次加载后由 Service Worker 缓存；长列表增量渲染（每次 40 条）；示范图懒加载 + CacheFirst 缓存。
- **离线**：PWA 预缓存全部静态资源，训练中断网也可用；示范图走 jsDelivr → GitHub Raw → 本地 SVG 插画三级回退。
- **可用性**：单手可达（主要操作在屏幕下半部）、按钮 ≥ 40px、数字等宽、输入框聚焦全选、尊重「减少动态效果」。
- **隐私**：数据只在本机，不上传任何服务器。
