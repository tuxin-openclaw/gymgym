# GymGym 交互与视觉设计说明

## 1. 设计原则

1. **训练中一切为「快」服务**：一组 = 一次点击（✓）。数据默认从上次带出，能不输入就不输入。
2. **单手可达**：主操作（开始训练、完成、添加动作、休息控制）放在屏幕下半部；底部抽屉（Bottom Sheet）承载二级操作，而不是弹窗跳页。
3. **可视化肌肉**：用自绘 SVG 人体肌肉图贯穿「选动作 → 看动作 → 看总结 → 看统计」，让「练了哪里」一目了然。
4. **正反馈**：完成组的勾选弹跳、休息结束振动、训练完成彩纸、PR 奖牌。
5. **深色优先**：健身房光线复杂、深色更省电更聚焦；同时提供浅色主题与跟随系统。

## 2. 视觉规范

| Token | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | #0B0D10 | #F3F4F7 | 页面背景 |
| `--surface` / `-2` / `-3` | #14171C / #1B1F26 / #252A33 | #FFF / #F1F2F5 / #E6E8ED | 卡片、输入框、标签 |
| `--ink` / `-2` / `-3` | #F3F5F8 / #B4BCC8 / #78818F | #12151A / #4B5462 / #8B93A1 | 主/次/弱文字 |
| `--accent` | **#C6F432 荧光青柠** | 同左 | 主按钮、完成状态、进度 |
| `--chart` | #C6F432 | #74A800 | 图表与肌肉热力（浅色下加深以保证对比） |
| 状态色 | warn #FFB547 · info #4DABF7 · danger #FF5D5D | | 热身组 / 递减组 / 力竭组、删除 |

- 部位色（标识用，固定顺序）：胸 #FF6B6B、背 #4DABF7、肩 #FFA94D、手臂 #B197FC、腿 #69DB7C、臀 #F783AC、核心 #FFD43B、有氧 #38D9A9。
- 字体：系统字体栈（PingFang SC / HarmonyOS Sans / 微软雅黑），数字一律 `tabular-nums` 等宽，避免计时跳动。
- 圆角：卡片 24px、按钮 16px、芯片全圆；层级靠背景明度而非阴影。
- 图标：Lucide（2px 描边）+ 自绘同风格器材图标（杠铃、哑铃、壶铃、绳索、器械、弹力带、曲杆、药球、瑞士球、泡沫轴）。
- 图片：动作示范图来自 free-exercise-db，两帧交替播放模拟动作；加载失败回退到「高亮目标肌群的迷你人体图」。

## 3. 关键页面与交互

### 3.1 底部导航
`首页 | 计划 | ▶ | 动作库 | 记录`。中间是凸起的主按钮：
- 无训练时 ▶ → 打开「开始训练」抽屉（自由训练 / 今日计划优先排列的计划列表）。
- 训练中变为「跳动的绿点 + 实时计时」，点击回到训练页 —— 在任何页面都能一眼看到并回到训练。

### 3.2 首页
自上而下：问候与日期 → 本周打卡条（7 天圆点，练过的天用计划颜色 + 🔥）→ 本周三项数据 → **今日训练卡片**（根据计划的训练日自动出现，渐变色背景、动作预览、一键开始）→ 本周练到的部位（人体热力图）→ 最近训练。
空状态：没有计划时引导去模板；有计划但今天休息时提示「可以休息，也可以自由训练」。

### 3.3 制定计划：选部位 → 选器材 → 选动作
计划编辑页：大标题输入名称 → 训练日（7 个圆形开关）→ 颜色 → 动作列表。
- 动作卡片默认折叠显示摘要「4 组 × 8 次 · 60kg · 休息 90s」，点击展开编辑：组数/次数用 **步进器**（−/+），目标重量用数字键盘，休息时间用芯片单选；上移/下移/移除。
- 「添加动作」打开全屏 **动作选择器**：
  1. **① 选部位**：横向滚动的部位卡片，每张卡片是高亮了该部位的迷你人体图，并显示该条件下的动作数量；
  2. **② 选器材**：带图标的器材芯片，只显示当前部位有动作的器材；
  3. **③ 选动作**：列表（示范图缩略图 + 中文名 + 英文名 + 器材 + 肌群），**多选**时右侧显示选择顺序编号，底部按钮「添加 N 个动作」。
  搜索框固定在顶部，支持中文、英文、肌肉名、器材名。
- 未保存离开时二次确认；底部固定「按此计划开始训练」。

### 3.4 训练进行中（核心页）
```
┌──────────────────────────────────┐
│ ⌄  推日·胸肩三头 ✎      [ 完成 ] │  ← 名称可改，计时实时
│    ⏱ 00:23:41                     │
│ ▓▓▓▓▓▓░░░░░░░░░░░░░░ 进度条       │
├──────────────────────────────────┤
│ [图] 杠铃卧推（中握）        ⋯   │
│      2/4 组 · 休息 90s            │
│  组  上次        重量  次数   ✓   │
│  1   60kg×10    [60]  [10]  [✓]  │ ← 完成后整行变绿
│  2   60kg×10    [62.5][ 8]  [ ]  │
│  [ + 添加一组 ]                   │
├──────────────────────────────────┤
│ ◯ 组间休息 01:12  [-15][+15][⏭] │ ← 浮动休息条
└──────────────────────────────────┘
```
- **一键完成**：点 ✓ 时若未填写，自动用「上次」数据补全；没有任何参考数据时 Toast 提示先填次数。
- 点「上次」列 = 把上次数据填入本组。
- 点组号 → 抽屉选择 正式/热身/递减/力竭，或删除该组；徽标分别显示 1/2/3、W、D、F 并着色。
- 动作「⋯」→ 抽屉：调休息时间、动作说明、替换动作、上移、下移、删除。
- 数字输入：`inputMode=decimal/numeric` 调起数字键盘，聚焦全选，方便直接覆盖。
- 完成一组 → 振动 15ms + 勾选弹跳 → 自动开始休息倒计时（环形进度）；结束时振动、提示音、Toast「休息结束，开始下一组！」。
- 「⌄」收起训练回到首页，训练在后台继续计时（底部主按钮显示计时）。
- 「完成」：有未勾选的组会提示「未完成的组不会被记录」；一组都没完成则提示是否放弃。

### 3.5 训练总结
彩纸动画 + 奖杯 → 四宫格数据 → 「打破了 N 项个人记录」（新值 vs 删除线旧值）→ 本次练到的肌肉 → 感受（😫😮‍💨🙂😄🔥）+ 心得 → 查看详情 / 完成；自由训练可「保存为计划」。

### 3.6 记录
- 顶部分段控件：**历史 | 统计**。
- 历史：月历，训练日用计划颜色实心圆标记，一天多练用小圆点；点某天筛选该天，否则显示整月列表。
- 统计：时间范围（4 周/12 周/1 年）→ 4 个 KPI → 训练趋势柱状图（容量/次数/时长切换，点按柱子看数值）→ 部位分布（人体热力 + 条形图）→ 个人记录 Top 8 → 体重曲线与记录。

### 3.7 动作详情
示范图两帧循环 → 中文名/英文名/标签（器材、类别、难度、复合/孤立、记录方式）→ **我的数据**（最大重量、预估 1RM、次数 + 进步折线图可切换指标 + 最近 5 次）→ 目标肌群人体图（主要实色、次要浅色）→ 动作要领 → 底部「加入计划」「加入训练（训练中）」。

## 4. 动效
| 场景 | 动效 |
| --- | --- |
| 抽屉 | 自下而上 320ms，ease-out-expo，背景淡入模糊 |
| 完成一组 / 选择动作 | 弹性缩放 pop 350ms |
| 卡片进入 | 上浮淡入 rise 450ms |
| 训练完成 | 36 片彩纸下落 + 奖杯弹出 |
| 训练中主按钮 | 绿点 ping 呼吸 |
所有动效在系统开启「减少动态效果」时关闭。

## 5. 无障碍
- 所有图标按钮带 `aria-label`；人体图每块肌肉有 `<title>` 中文名。
- 状态不只靠颜色：组类型同时显示字母，PR 同时有图标和文字。
- 文字对比度：正文 ≥ 4.5:1；浅色主题下图表改用更深的 `--chart`。
